```sh
sudo vi /etc/httpd/conf.d/mpm_prefork.conf
```

以下の中身を書く。

```sh
<IfModule mpm_prefork_module>
    StartServers             3
    MinSpareServers          3
    MaxSpareServers          5
    MaxRequestWorkers       20
    MaxConnectionsPerChild 1000
</IfModule>
```

再起動。

```sh
$ sudo apachectl configtest

$ sudo systemctl start httpd
```

## 10月17日(土)

プログラミング基礎同演習のレポート採点。

WSL(Ubuntu)で、Markdown PDFで日本語がうまく表示されないことへの対処。

WSLに日本語フォントインストール。

```sh
sudo apt update
sudo apt install fonts-noto-cjk fontconfig
```

Google Chromeをインストール。

```sh
wget https://dl.google.com/linux/direct/google-chrome-stable_current_amd64.deb
sudo dpkg -i google-chrome-stable_current_amd64.deb
```

VSCodeの「Preferences: Open Remote Settings (JSON) (WSL: Ubuntu)」を開いて以下を追加。

```json
{
  "markdown-pdf.format": "A4",
  "markdown-pdf.printBackground": true,
  "markdown-pdf.displayHeaderFooter": false,
  "markdown-pdf.chromium.autoDownload": true,
  "markdown-pdf.styles": [".vscode/markdown-pdf.css"]
}
```

MarkdownPDFを実施したいプロジェクトに`.vscode/markdown-pdf.css`を作り、以下を記述。

```css
body {
  font-family: "Noto Sans CJK JP", sans-serif;
  font-size: 11pt;
  line-height: 1.6;
}

pre,
code {
  font-family: monospace;
}
```

おおー、できた。これまでわざわざWindows側でVSCodeで開きなおしてMarkdown PDFを実行していたが、これでWSL上で作業が完結する。レポートの返事をMarkdown PDFを使って作っていたので、だいぶうれしい。
