物性研時代からアップグレードしてきたMacをクリーンインストールして、身も心もスッキリしたんだけど、なんか日本語入力がおかしい。Mac標準のIMEがどうしても合わなくてGoogleのを入れたんだけど、入力ソースとして認識しないときがある。例えばターミナルとVSCodeは入力できるけど、Slackに入力できない(「かな」キーを押しても空白が入力されてモードが切り替わらない)ことがあってとても困る。

Mac標準のIMEは変換精度云々より、「決定した」と思った単語が決定されていないことが頻発する(エンターを押しても器決定されていない？)ので、Google 入力を使いたいのだが。ATOKとか入れたら解決するんだろうか。

Pandocを入れようとしたらIntel MacのTahoeがなかった。ソースから入れることに。

```sh
brew install --build-from-source pandoc
```

gnuplotもボトルがない。pcre2が必要らしい。これだけソースからビルド。

```sh
brew install --build-from-source pcre2
```
